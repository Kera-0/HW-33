В этой работе я решал задачу распознавания именованных сущностей на датасете CoNLL-2003. За основу я взял модель bert-base-cased, сначала дообучил ее на NER, а затем попробовал уменьшить разными способами.

Из рабочего окружения не было доступа к Hugging Face, поэтому я скачал датасет и модель на свой компьютер, а затем перенес их на Jupyter-сервер.

При токенизации слово может разбиться на несколько подслов. Первому подслову я оставил исходную метку, для остальных заменил B на I. Специальным токенам и padding я присвоил метку -100, чтобы они не участвовали в вычислении ошибки.

После дообучения учителя я получил на тесте 0,9117 F1 при оценке по словам. Если считать метрику по всем подсловам, получается 0,8973. Я также запустил обучение с другим seed и получил 0,8951 по подсловам. В остальных экспериментах я использовал первого учителя.

При факторизации я заменил матрицу эмбеддингов двумя матрицами ранга 64. Для их инициализации я использовал приближенное SVD, а затем дообучил модель. Размер модели уменьшился со 107,7 до 87,4 млн параметров. F1 на тесте составила 0,8865 по словам и 0,8727 по подсловам.

Для дистилляции я взял ученика с четырьмя слоями и скрытым размером 384 и обучил его с нуля по разметке и предсказаниям учителя. В ошибке я сложил кросс-энтропию и KL-дивергенцию с температурой 2. Ученик содержит 18,4 млн параметров и получил 0,7544 F1 по словам и 0,7031 по подсловам.

В дополнительных экспериментах я проверил общие веса слоев, остаточные низкоранговые адаптеры, приближение промежуточных состояний и отношения внимания MiniLMv2. На тесте F1 по словам составила соответственно 0,7548, 0,7405, 0,7884 и 0,7822. Вариант с адаптерами отличается от LoRA внутри матриц внимания и в этом запуске не улучшил результат по сравнению с обычным шерингом.

Еще одного ученика я инициализировал весами учителя после структурного прунинга. Для него я взял слои 3, 6, 9 и 12 и первые координаты весов, без поиска наиболее важных каналов. После дистилляции он получил 0,8276 F1 по словам и 0,7953 по подсловам.

Для сравнения прунинга я использовал Wanda и приближенную реализацию SparseGPT. В обоих случаях я обнулил половину весов линейных слоев энкодера. F1 по словам составила 0,7518 для Wanda и 0,7557 для SparseGPT. Плотный файл весов при этом не становится меньше: для экономии памяти нужен разреженный формат. В реализации SparseGPT я собрал статистики всех слоев до прунинга.

Я проводил обучение на NVIDIA H100. Лучшую контрольную точку каждого эксперимента я выбирал по F1 на validation, посчитанной по подсловам.
